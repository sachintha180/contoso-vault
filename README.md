# Contoso Vault

Student-facing material for the STEM Link Python sessions: starter files, test specifications and sample data.

## Getting started

Do these once, in Session 01:

1. Fork this repository on GitHub, so you have your own copy.
2. Run `git clone` with your fork's web address.
3. Open the `01-first-encrypted-message` folder inside your clone in VS Code.

## At the start of each session, from Session 02

1. Push your commits from the last session.
2. On your fork's GitHub page, choose Sync fork, then Update branch. Never choose Discard commits, which deletes your work.
3. Run `git pull`.
4. Open this session's folder in VS Code, and work inside it.

## Rules

- Never edit the files provided here. Add your own files beside them.
- Your fork is public. It is your portfolio of the coding work from every session: labs, unaided tasks and take-homes.
